Changer les images et photos

Bibliothèque de médias, logo, galerie et fonds de page

🖼️ 3.1 — UPLOADER UNE NOUVELLE IMAGE Médias › Ajouter

Avant d'utiliser une image dans le site, vous devez d'abord l'uploader dans la bibliothèque WordPress.

  • 1
    Dans le menu gauche, cliquez sur Médias
  • 2
    Cliquez sur "Ajouter"
  • 3
    Faites glisser votre photo dans la zone pointillée, ou cliquez "Sélectionner des fichiers"
  • 4
    Attendez la fin du chargement (barre à 100 %) → l'image est disponible
📸
Déposez vos fichiers ici
ou
Sélectionner des fichiers
Formats : JPG, PNG, WEBP — Taille max recommandée : 2 Mo
Conseils : photos en format paysage, résolution minimale 1920×1080 px pour les grandes zones. Compressez avant upload pour garder un site rapide.
🏷️ 3.2 — CHANGER LE LOGO DU RESTAURANT Personnaliser › Identité du site › Logo
  • 1
    Allez dans Apparence › Personnaliser
  • 2
    Cliquez sur "Identité du site" (tout en haut de la liste, avant "Restaurant Theme")
  • 3
    Cliquez sur "Sélectionner le logo"
  • 4
    Choisissez une image dans la bibliothèque ou uploadez un nouveau fichier
  • 5
    Cliquez sur "Publier"
Format idéal : PNG avec fond transparent, hauteur entre 150 et 300 px. La taille d'affichage se règle dans Personnaliser › Header › "Hauteur du logo (px)".
🖼️ 3.3 — GALERIE PHOTOS (CAROUSEL — JUSQU'À 19 IMAGES) Personnaliser › Carousel / Galerie
  • 1
    Allez dans Apparence › Personnaliser › Carousel / Galerie
  • 2
    Modifiez le Label et le Titre de la section si besoin
  • 3
    Pour chaque emplacement (Image 1 à 19) : cliquez "Sélectionner image"
  • 4
    Optionnellement, renseignez une légende dans "Légende image X" (texte affiché sur la photo)
  • 5
    Cliquez sur "Publier"
Seules les images renseignées s'affichent — inutile de remplir les 19 emplacements.

Configuration des réservations

Capacité, fermeture, horaires et emails automatiques

Menu gauche › Réservations › Configuration
La page de configuration a deux onglets : 🇮🇹 Italiano et 🇬🇧 English. Les paramètres généraux (capacité, jours, emails expéditeur) sont sur l'onglet IT. Les templates d'emails se configurent sur chaque onglet séparément.

ParamètreCe que ça fait
Confirmation automatiqueCoché = réservation confirmée dès réception, email envoyé immédiatement. Décoché = reste "En attente" jusqu'à votre validation manuelle.
Nombre max. de couvertsLe formulaire n'accepte pas un nombre supérieur à cette valeur. Maximum possible : 12.
Jours de fermetureLes jours cochés sont bloqués dans le calendrier — les clients ne peuvent pas les sélectionner.
Pause après-midiLes créneaux entre ces deux heures sont masqués dans le formulaire (ex : 15:30–17:30).
Fermeture du soirAucun créneau proposé après cette heure. Dernier créneau disponible = cette heure - 30 min.

Changer les horaires d'ouverture

Footer affiché sur le site + logique du formulaire de réservation

⚠️ DEUX ENDROITS INDÉPENDANTS À METTRE À JOUR
Important : les horaires existent en deux endroits. Il faut les mettre à jour ensemble lors de chaque changement.

1️⃣ Affichage dans le footer

Où : Apparence › Personnaliser › Footer

Contrôle les horaires visibles en bas de chaque page.

2️⃣ Logique du formulaire

Où : Réservations › Configuration

Contrôle les jours et heures bloqués dans le formulaire de réservation.

🕐 MODIFIER LES HORAIRES DANS LE FOOTER Personnaliser › Footer
  • 1
    Allez dans Apparence › Personnaliser › Footer
  • 2
    Faites défiler jusqu'aux champs "Ligne X — Jours" et "Ligne X — Horaires" (5 lignes disponibles)
  • 3
    Modifiez les jours et les heures selon les nouveaux horaires
  • 4
    Cliquez sur "Publier"

🔧 RÉSOLUTION DE PROBLÈMES FRÉQUENTS
ProblèmeSolution
Je ne reçois plus les emails de notificationVérifiez l'email admin dans Réservations › Configuration. Vérifiez aussi vos spams.
Les clients ne reçoivent pas les emailsAllez dans Config. et cliquez "Envoyer un email de test". Si ça échoue, contactez votre hébergeur.
J'ai cliqué "Publier" mais rien ne changeVidez le cache du navigateur : Ctrl + Maj + R (Windows) ou Cmd + Maj + R (Mac).
Les horaires du footer ne se mettent pas à jourN'oubliez pas de cliquer "Publier" dans le Personnalisateur après modification.
Une image ne s'affiche pasL'image est peut-être trop petite. Utilisez au minimum 1920×1080 px pour les grands fonds.
Je veux supprimer une photo de la galerieDans Personnaliser › Carousel / Galerie, cliquez sur l'image concernée puis "Supprimer". Publiez.
Je ne retrouve pas un réglageTextes/images : Apparence › Personnaliser. Réservations : Réservations › Configuration.
🚫 À ne jamais faire : ne jamais supprimer ni désactiver le thème "restaurant-theme" ni le plugin "Restaurant Reservation". Ne pas modifier les fichiers via "Apparence › Éditeur de fichiers" sans contacter votre développeur.
